# EP Route Planner (Claude plugin)

The Claude plugin version of the EP Route Planner skill by David MacVittie. It builds route advances for executive protection drive teams.

The main project, sample packet, how-to and feedback all live at
https://github.com/davidmacvittie/ep-route-planner

## Recommended connectors

Connect all three in Claude before your first run. The skill checks at the start and tells you which are missing.

- **Mapbox:** maps, routes, turn-by-turn steps and drive times. Without it, map pages are empty and times are estimates.
- **TomTom:** live traffic, closures and roadworks, and alternate routes on short city legs. Without it, closures come only from city websites.
- **AccuWeather:** the forecast for the day. Without it, weather comes from web search or the normal for the date.

Comments and suggestions: please open an issue or discussion on the main repo.
